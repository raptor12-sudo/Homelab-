# Services

Un dossier par service, avec son `docker-compose.yml` ou sa procédure d'installation, et un `.env.example` si des variables sont nécessaires.

## Prévus, dans l'ordre

1. AdGuard Home : DNS interne
2. Traefik : reverse proxy
3. Vaultwarden : gestionnaire de mots de passe
4. Uptime Kuma : supervision de disponibilité
5. Prometheus et Grafana : métriques
